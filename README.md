## Sobre o projeto

O **Fácil Click** é um aplicativo desenvolvido em Python para promover a inclusão digital de pessoas idosas por meio de uma interface gráfica acessível, intuitiva e simplificada.

O projeto foi desenvolvido durante as Atividades Extensionistas do curso de Engenharia da Computação, tendo como objetivo facilitar o acesso aos principais serviços digitais utilizados no cotidiano.

## Aplicação prática

O aplicativo foi apresentado utilizando um notebook no Centro de Convivência da Melhor Idade do Jardim Remanso Campineiro, em Hortolândia/SP.

Os testes foram realizados voluntariamente por pessoas idosas que aceitaram participar da atividade.

Para preservar a privacidade dos participantes, não foram realizados registros fotográficos que permitissem sua identificação.

Os feedbacks obtidos durante a demonstração foram positivos, destacando principalmente:

* facilidade de navegação;
* boa organização visual;
* botões de fácil identificação;
* textos legíveis;
* simplicidade de utilização.
